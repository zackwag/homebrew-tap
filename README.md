# Homebrew Tap

Homebrew formulae and casks by [Zack Wagner](https://github.com/zackwag).

## Install

```bash
# DotBuddy — manage shell aliases and environment variables
brew install zackwag/tap/dotbuddy

# mac-temp — read CPU/thermal sensor temperatures on Apple Silicon
brew install zackwag/tap/mac-temp
```

## Update

```bash
brew upgrade dotbuddy
brew upgrade mac-temp
```
